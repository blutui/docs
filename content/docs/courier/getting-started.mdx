## Features

- Experience the power of Blutui from your local environment using `courier dev`, to easily keep your code in sync.
- Easily push code to your project using the simple `courier push` command.
- Get started with a new project using `courier create` to scaffold it from a Canvas.

## Start using Courier

### Installation

`courier` works on macOS, Windows, and Linux. To install it, open a terminal and run the install script for your system:

```bash tab="macOS & Linux"
curl -fsSL https://blutui.com/courier/install.sh | sh
```

```powershell tab="Windows PowerShell"
irm https://blutui.com/courier/install.ps1 | iex
```

```batch tab="Windows CMD"
curl -fsSL -o install.cmd https://blutui.com/courier/install.cmd && install.cmd && del install.cmd
```

The install script downloads the latest release and verifies its checksum before installing it.


You can also install with a package manager:

```bash tab="Homebrew"
brew install --cask blutui/courier/courier
```

```bash tab="Scoop"
scoop bucket add blutui https://github.com/blutui/bucket-courier.git
scoop install blutui/courier
```

<Callout type="warning">
On Windows, **Scoop** must be run in PowerShell, not CMD. **Git** is required to install Scoop buckets.
</Callout>

Open a new terminal and check that `courier` is installed:

```bash
courier version
```

To upgrade, install a specific version, or uninstall, see the guide for your operating system:

### Log in

Courier uses a Courier token to access your Blutui projects. Create one in your [Agency Console](https://console.blutui.com) under **Profile → Apps → Access tokens**, save it to a `token.txt` file, and log in:

```bash tab="macOS & Linux"
courier login --token < token.txt
```

```powershell tab="Windows PowerShell"
Get-Content token.txt -Raw | courier login --token
```

Delete `token.txt` once you're logged in. For step-by-step instructions, see [Create a Courier token](/docs/courier/installation/macos#create-a-courier-token).
