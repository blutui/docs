## Install Courier

Open a terminal and run the install script, or install with Homebrew:

```bash tab="Install script"
curl -fsSL https://blutui.com/courier/install.sh | sh
```

```bash tab="Homebrew"
brew install --cask blutui/courier/courier
```

## Verify the installation

Open a new terminal and run:

```bash
courier version
```

A working installation prints the installed version number.

## Upgrade Courier

To upgrade to the latest version of `courier`, use the same method you installed with:

```bash tab="Install script"
curl -fsSL https://blutui.com/courier/install.sh | sh
```

```bash tab="Homebrew"
brew upgrade --cask courier
```

## Install a specific version

Pass `--version` to the install script:

```bash
curl -fsSL https://blutui.com/courier/install.sh | sh -s -- --version v1.7.3
```

To install to a different directory, pass `--install-dir`:

```bash
curl -fsSL https://blutui.com/courier/install.sh | sh -s -- --install-dir ~/bin
```

## Uninstall Courier

```bash tab="Install script"
rm "$(command -v courier)"
```

```bash tab="Homebrew"
brew uninstall --cask courier
```

<Callout type="warning">
If `courier` was installed to `/usr/local/bin`, you may need to run the `rm` command with `sudo`.
</Callout>

## Firefox on macOS

To use `courier dev` on Firefox, you need to install `nss` (Network Security Services). NSS is a set of libraries designed to support cross-platform development of security-enabled client and server applications.

To install NSS on macOS run:

```bash
brew install nss
```
