## Installation

Install Courier on macOS, Windows or Linux:

```bash tab="macOS & Linux"
curl -fsSL https://blutui.com/courier/install.sh | sh
```

```bash tab="Homebrew"
brew install --cask blutui/courier/courier

```bash tab="PowerShell (Windows)"
irm https://blutui.com/courier/install.ps1 | iex
```

```bash tab="CMD (Windows)"
curl -fsSL -o install.cmd https://blutui.com/courier/install.cmd && install.cmd && del install.cmd
```


```bash tab="Scoop"
scoop bucket add blutui https://github.com/blutui/bucket-courier.git
scoop install blutui/courier
```

Open a new terminal and check that Courier is installed:

```bash
courier version
```

## Log in

Log in with your Blutui account:

```bash
courier login
```

Courier shows a login code and opens Blutui in your browser. Paste the code and approve the login, and you're ready to go.

<Callout>
In CI or anywhere without a browser, [log in with an access token](/docs/courier/commands#log-in-with-an-access-token) instead.
</Callout>
