## Install Courier

Open a terminal and run the install script:

```bash
curl -fsSL https://blutui.com/courier/install.sh | sh
```

## Verify the installation

Open a new terminal and run:

```bash
courier version
```

A working installation prints the installed version number.

## Upgrade Courier

To upgrade to the latest version of `courier`, run the install script again:

```bash
curl -fsSL https://blutui.com/courier/install.sh | sh
```

## Install a specific version

Pass `--version` to the install script:

```bash
curl -fsSL https://blutui.com/courier/install.sh | sh -s -- --version v1.7.3
```

To install to a different directory, pass `--install-dir`:

```bash
curl -fsSL https://blutui.com/courier/install.sh | sh -s -- --install-dir ~/bin
```

## Uninstall Courier

Remove the `courier` binary:

```bash
rm "$(command -v courier)"
```

<Callout type="warning">
If `courier` was installed to `/usr/local/bin`, you may need to run this command with `sudo`.
</Callout>

## Firefox on Linux

To use `courier dev` on Firefox, you need to install `nss` (Network Security Services). NSS is a set of libraries designed to support cross-platform development of security-enabled client and server applications.

To install NSS on Linux use the package manager that applys to your system:

- apt `apt install libnss3-tools`
- yum `yum install nss-tools`
- zypper `zypper install mozilla-nss-tools`
