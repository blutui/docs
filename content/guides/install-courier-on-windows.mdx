## Introduction

Courier is a development tool that allows you to write code locally and view the results instantly. Once you're satisfied with your work, you can push it to your Blutui project for review. Courier is designed to offer the best of both worlds by integrating local workflow with the cloud, thereby making development faster, more enjoyable, and more creative. This guide walks you through the process of installing and setting up Courier on a Windows machine.

## Installation

<Steps>
<Step>
### Install Courier
Open PowerShell or Command Prompt and run the install script for your shell. If you prefer [Scoop](https://scoop.sh/), use the Scoop tab instead:

```powershell tab="PowerShell"
irm https://blutui.com/courier/install.ps1 | iex
```

```batch tab="CMD"
curl -fsSL -o install.cmd https://blutui.com/courier/install.cmd && install.cmd && del install.cmd
```

```powershell tab="Scoop"
scoop bucket add blutui https://github.com/blutui/bucket-courier.git
scoop install blutui/courier
```

<Callout>
Your prompt starts with `PS C:\` in PowerShell and `C:\` in CMD. You don't need to run the install script as Administrator.
</Callout>

<Callout type="warning">
**Scoop** must be run in PowerShell, not CMD. Git is also required to install Scoop buckets.
</Callout>
</Step>

<Step>
### Verify the installation
Open a new terminal window and run:

```powershell
courier version
```

A working installation prints the installed version number.
</Step>
</Steps>
