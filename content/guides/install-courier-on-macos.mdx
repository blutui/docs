## Introduction

Courier is a development tool that allows you to write code locally and view the results instantly. Once you're satisfied with your work, you can push it to your Blutui project for review. Courier is designed to offer the best of both worlds by integrating local workflow with the cloud, thereby making development faster, more enjoyable, and more creative. This guide outlines the steps to install and set up Courier on a macOS machine.

## Installation

<Steps>
<Step>
### Install Courier
Open your terminal and run the install script. If you prefer [Homebrew](https://brew.sh/), use the Homebrew tab instead:

```bash tab="cURL"
curl -fsSL https://blutui.com/courier/install.sh | sh
```

```bash tab="Homebrew"
brew install --cask blutui/courier/courier
```

The install script downloads the latest release and verifies its checksum before installing it.
</Step>

<Step>
### Verify the installation
Open a new terminal window and run:

```bash
courier version
```

A working installation prints the installed version number.
</Step>
</Steps>

## Additional steps for Firefox users

If you're using Firefox, you'll need to install Network Security Services (NSS) to use `courier dev`:

```bash
brew install nss
```
